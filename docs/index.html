How step-free is Berlin?

Districts

    How to read this map
    1. Every column is a hexagon of about 0.7 km². Height = number of places; colour = what the map says about wheelchair access there.
    2. OpenStreetMap is mapped by volunteers. "Unknown" doesn't mean inaccessible: nobody has checked yet. Tools like Wheelmap let anyone add it.
    3. "Yes" means step-free entrance and main rooms; "limited" means partly (e.g. one step, or no accessible toilet).

    Data

    OpenStreetMap contributors (ODbL), Geofabrik Berlin extract. Places = shops, food, health, public and cultural venues, toilets (street furniture excluded). Wheelchair values as tagged in OSM (also edited via Wheelmap).
